# PACKMATE

여행·출장·교육·방문 등 **이동 목적과 일정에 맞춰 준비물과 출발 전 할 일을 관리하는 정적 웹앱**입니다. 조건별 체크리스트를 만들고, 개인 필수품과 과거 누락 기록을 다음 일정에 반영할 수 있습니다.

## 프로젝트 파일

- `index.html` — 앱 화면 및 상대 경로로 연결한 정적 자원
- `styles.css` — 반응형 화면 스타일
- `app.js` — 일정, 체크리스트, 브라우저 저장 기능
- `PACKMATE_logo.png` — 시작 화면 및 헤더 로고
- `plan.md` — 프로젝트 기획서

빌드 도구나 패키지 설치는 필요하지 않습니다.

## 실행 방법

1. 프로젝트 파일을 같은 폴더 구조로 둡니다. 특히 `index.html`, `styles.css`, `app.js`, `PACKMATE_logo.png`는 저장소 루트에 둡니다.
2. `index.html`을 브라우저에서 열어 실행합니다. 브라우저의 `file://` 보안 정책에 따라 저장 동작이 제한될 수 있으면 정적 HTTP 서버나 GitHub Pages 주소에서 확인하세요.
3. GitHub Pages에서는 저장소에 게시된 HTTPS 주소로 접속해 사용할 수 있습니다.

## 주요 기능

- 여행·휴가, 출장·업무, 교육·행사, 방문·개인 일정 목적 선택
- 국내 지역 또는 해외 국가와 이동수단, 기간, 숙박 여부, 활동 입력
- 조건에 맞춘 준비물 및 출발 전 확인 업무 생성
- 준비물 수납과 업무 완료 진행률을 분리해 표시
- 준비물 추가·수정·삭제, 개인 필수품 저장 및 재사용
- 누락 항목 기록과 다음 일정의 우선 점검
- 여러 일정의 브라우저 저장, 다시 열기 및 삭제
- 입국 관련 내용은 확정적 법률 판정 대신 공식 안내 확인을 권장

## 데이터 및 개인정보

일정과 개인 필수품은 현재 브라우저의 `localStorage`에 저장됩니다. 서버로 전송되거나 다른 기기와 자동 동기화되지 않으며, 브라우저 데이터 삭제 시 기록이 사라질 수 있습니다. 앱은 `packmate.trips.v1` 및 `packmate.essentials.v1` 키를 사용합니다.

`file://`로 실행한 브라우저 저장 공간과 GitHub Pages의 HTTPS 사이트 저장 공간은 서로 다를 수 있으므로, 기존 브라우저 기록이 배포 사이트로 자동 이전된다고 가정하지 마세요. 민감하거나 타인과 공유하면 안 되는 정보는 입력하지 않는 것을 권장합니다.

## 무료 GitHub Pages 배포

GitHub 저장소 생성과 원격 Push는 이 준비 단계에서 수행하지 않았습니다. 배포할 때 다음 순서로 진행하세요.

1. GitHub에 저장소를 만든 뒤 프로젝트 파일을 저장소 루트에 올립니다. `index.html`, `styles.css`, `app.js`, `PACKMATE_logo.png`는 서로 현재 경로 관계를 유지해야 합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. 배포 브랜치(예: `main`)와 폴더 **`/(root)`**를 선택하고 저장합니다.
5. Pages가 제공하는 사이트 주소에서 공개 상태를 확인합니다. 첫 배포 및 변경 반영에는 시간이 걸릴 수 있습니다.

현재 HTML은 CSS, JavaScript, 로고를 저장소 루트 기준의 상대 경로(`styles.css`, `app.js`, `PACKMATE_logo.png`)로 참조합니다. 따라서 프로젝트 사이트 주소가 `/<저장소명>/` 하위 경로인 경우에도 루트 절대 경로를 요구하지 않습니다. 저장소 내 경로를 바꾸면 HTML의 상대 경로도 함께 맞춰야 합니다.

## 외부 서비스 및 의존성

앱 로직은 HTML, CSS, 브라우저 기본 JavaScript와 `localStorage`만 사용하며, 서버·유료 API·외부 JavaScript 라이브러리·패키지 설치가 필요하지 않습니다. 현재 `index.html`은 글꼴 표시를 위해 Google Fonts의 웹 글꼴을 선택적으로 요청합니다. 네트워크에서 글꼴을 가져오지 못해도 CSS 대체 글꼴로 표시되며, 앱 기능 자체는 해당 서비스에 의존하지 않습니다.
